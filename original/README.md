# Original script

`Spiderman.py` is the original single-file script by [nourhan11atef](https://github.com/nourhan11atef/Spiderman_Recreate_image), kept unchanged for reference.

It always draws `spiderman.png` and ignores `.env`. To draw your own image, run `python main.py` from the project root instead.

To run this original version, run it from the project root so it can find the image:

```bash
python original/Spiderman.py
```
